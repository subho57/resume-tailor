Job description


We’re looking for a Backend Engineer with 3–5 years of experience who is passionate about building high-quality, scalable systems. You will contribute to the development of backend services for our product, working closely with experienced engineers, designers, and product stakeholders.

In this role, you’ll gain hands-on experience in modern backend technologies, cloud-native development, and microservices architecture, while helping deliver reliable and performant features.



Roles and Responsibilities:


Contribute to the design and development of backend services and APIs

Develop new features using JavaScript / TypeScript (Node.js)

Write clean, maintainable, and testable code following best practices

Work with SQL databases to design schemas and write efficient queries

Deploy and manage services on Google Cloud Platform (GCP), especially using Cloud Run

Containerise applications using Docker

Participate in code reviews and incorporate feedback to improve code quality

Debug, troubleshoot, and resolve backend issues and bugs

Assist in improving the performance, reliability, and scalability of services

Contribute to documentation for APIs, services, and workflows

Work closely with frontend engineers, QA, and product manager
