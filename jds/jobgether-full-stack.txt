About the job
This position is listed on behalf of a partner company, who manages all applications and next steps. Our partner is looking for a Full Stack Engineer based in India.

This role offers the opportunity to build scalable, reliable software products while working across backend services, APIs, cloud infrastructure, and frontend integrations.

You will contribute to the design and delivery of high-quality features in a collaborative product engineering environment.

The position combines hands-on development with opportunities to improve system performance, reliability, and architecture.

You will work closely with engineers, designers, QA teams, and product stakeholders to create impactful solutions.

This is an ideal opportunity for an engineer who enjoys ownership, problem-solving, and building modern cloud-native applications.

The role provides exposure to technologies including Node.js, TypeScript, Google Cloud Platform, Docker, and microservices architectures.

Accountabilities

The Full Stack Engineer will contribute to the development and improvement of scalable software systems, supporting product delivery through strong engineering practices and technical collaboration.

Design, develop, and maintain backend services, APIs, and product features.
Build reliable applications using JavaScript, TypeScript, Node.js, and modern backend frameworks.
Develop clean, maintainable, and testable code following software engineering best practices.
Design database schemas, write efficient queries, and optimise SQL database performance.
Deploy and manage cloud-based applications using Google Cloud Platform, including Cloud Run.
Containerise applications using Docker and support cloud-native deployment workflows.
Participate in code reviews and contribute to improving overall code quality.
Debug, troubleshoot, and resolve technical issues across applications and services.
Improve system performance, scalability, and reliability through continuous optimisation.
Create and maintain technical documentation for APIs, services, and workflows.
Collaborate closely with frontend engineers, QA professionals, and product teams to deliver complete solutions.

Requirements

The ideal candidate has strong full stack engineering fundamentals, hands-on backend development experience, and the ability to build scalable applications in a modern cloud environment.

3-5 years of professional experience in software engineering, with strong backend development experience.
Proficiency in JavaScript and TypeScript.
Hands-on experience with Node.js and backend frameworks such as Express, Fastify, or Hono.
Strong understanding of RESTful API design and backend development best practices.
Experience working with SQL databases such as PostgreSQL or MySQL, including query optimisation.
Experience deploying and managing applications on Google Cloud Platform.
Hands-on experience with Docker and containerised application deployments.
Understanding of microservices architecture and distributed systems concepts.
Familiarity with CI/CD pipelines and version control systems such as Git.
Strong problem-solving skills and attention to detail.
Ability to take ownership of features and deliver end-to-end solutions.
Strong collaboration skills and ability to work effectively within cross-functional teams.

Preferred Qualifications

Experience with messaging systems such as Pub/Sub, Kafka, or similar technologies.
Familiarity with NoSQL databases such as Firestore or MongoDB.
Exposure to Infrastructure as Code tools such as Terraform.
Experience with monitoring, logging, and observability tools.
Knowledge of system design, scalability principles, and high-traffic applications.
Experience working in Agile or Scrum environments.
Previous experience building SaaS products.

Benefits

Fully remote working opportunity from India.
Competitive salary range of ₹15-20 LPA.
Opportunity to work on scalable, modern software products.
Exposure to cloud-native technologies and distributed systems.
Collaborative environment with experienced engineers and product teams.
Opportunities to take ownership of impactful technical projects.
Flexible remote setup with occasional team visits to the Chennai office twice per year.
Opportunity for continuous learning and growth through hands-on engineering challenges.
