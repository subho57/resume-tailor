About the Role
As a Software Engineer II on the Auth & Access team, you will contribute to building, scaling, and maintaining the core authentication and identity services that power the JumpCloud platform. You will work closely with a globally distributed engineering team to deliver reliable features across our Go, Python, and Node.js backend stacks.

This role focuses heavily on implementing modern, secure web authentication protocols, integrating seamless identity workflows, and aggressively leveraging AI-assisted development tools (like GitHub Copilot and Cursor) to write high-quality code and accelerate feature velocity.

What You Will Do:
Backend Development: Develop, test, and deploy scalable, secure, and well-documented microservices using Go, Python, and/or Node.js.

Auth & Identity Implementation: Write and maintain backend code supporting core Auth/IAM technologies, including OAuth 2.0, OpenID Connect (OIDC), JSON Web Tokens (JWT), and single sign-on (SSO) flows.

AI-Driven Efficiency: Actively utilize AI-assisted development tools (e.g., GitHub Copilot, Cursor) to automate code generation, write robust automated unit tests, and speed up debugging cycles.

Cloud Infrastructure: Work with containerized applications using Docker and Kubernetes, and deploy cloud-native services across AWS Cloud Services (EC2, S3, Lambda, DynamoDB).

Quality & Automation: Design automated test cases for both new features and legacy services, utilizing CI/CD pipelines to enforce automated quality gates.

Collaborative Engineering: Partner with product managers and senior engineers across multiple time zones to refine requirements, assess technical feasibility, and participate in thorough code reviews.

What We’re Looking For:
Experience: 3–5 years of professional experience in software development, with a strong emphasis on backend systems and API development.

Core Technical Stack: Proficiency in Go, Node.js, and/or Python.

Authentication Foundations: A solid understanding of modern web security and authentication architectures, specifically OAuth 2.0, OIDC, and JWT.

Cloud & DevOps Basics: Practical experience deploying software on AWS and a functional understanding of container orchestration (Kubernetes) or Infrastructure as Code concepts (Terraform).

AI Tool Fluent: Demonstrated experience using AI coding assistants to increase individual velocity, track down bugs, and improve overall code quality.
