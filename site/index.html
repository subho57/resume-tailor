resume-tailor

One hand-edited resume drifts across a dozen applications. Under pressure to match a job description, it's tempting to inflate a keyword you don't really have — that collapses in an interview. resume-tailor keeps one JSON source of truth and tailors it honestly to each job's own vocabulary: select and rephrase real experience, never invent it.

Entirely free. No account, no subscription — a static binary, plus the Claude Code or GitHub Copilot subscription you already have. --install-skill drops the tailoring workflow into your existing ~/.claude/skills/ or ~/.copilot/skills/, whichever you already use.

Install

curl -fsSL https://subho57.github.io/resume-tailor/install.sh | bash

macOS and Linux. Windows support is in Beta — download the latest Windows build directly.

Try it now — right in this page

Runs entirely in your browser — nothing is uploaded.
