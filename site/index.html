Frequently Asked Questions

How does resume-tailor avoid fabricating skills or experience?

The tailoring prompt and skill pipeline operate strictly on the content present in your JSON source of truth. It can rephrase sentences to highlight relevant terminology from the job description, but it is explicitly forbidden from inventing job titles, companies, dates, or unverified achievements.

Is my resume data stored or sent to any server?

No. When using the CLI tool, it runs completely on your local machine. When using this browser page, the JSON parsing and DOCX generation are executed 100% client-side in WebAssembly/JavaScript. Nothing is ever transmitted to a backend server.

How do I use it with Claude Code or GitHub Copilot?

Run tailor-resume --install-skill. This copies both bundled skills (jd-tailored-resume and master-resume-builder) into your local ~/.claude/skills/ and ~/.copilot/skills/ directories, giving your AI coding assistant full context on how to build and tailor your resume without hallucinatory facts.

What formats does resume-tailor export to?

The CLI exports clean Microsoft Word .docx documents as well as formatted .pdf files (via headless LibreOffice/Word when available). The web interface generates high-fidelity .docx files directly in your browser.
