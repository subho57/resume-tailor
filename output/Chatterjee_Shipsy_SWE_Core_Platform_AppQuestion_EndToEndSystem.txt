Turbot Guardrails is a Preventive Security Posture Management (PSPM) SaaS platform — it delivers real-time preventive controls for customers' cloud infrastructure, with automated policy enforcement and remediation, across enterprise customers in finance, healthcare, and government. I designed and built the internal REST API microservice in Go, using the Gin framework, that powers part of that backend — as a greenfield build, meaning there was no existing service to extend or copy patterns from; every architectural decision was mine to make from a blank slate.

Because this sits inside a security product, the design constraints weren't just "make it work" — they were "make it work securely, and make it interoperate correctly with the rest of the platform." I secured every endpoint with OAuth 2.0 authentication via Auth0 rather than rolling my own auth, since a security-posture platform can't afford to be the weak link in its own auth story. I containerized the service with Docker and deployed it to AWS EC2 so it would run consistently regardless of environment, and I wired it in as a gRPC client talking to several other internal microservices — which meant getting the service-to-service contracts right, since a mismatch there breaks correctness silently rather than loudly.

What made it non-trivial in practice was that none of these pieces could be gotten "mostly right" in isolation and fixed up later — authentication, containerization, and inter-service communication all had to be correct together for the service to be trustworthy in a security product from day one. I owned the full lifecycle myself: design, implementation, testing, and deployment, and it's been running as a real part of Guardrails' backend since.
